CaseLab — сайт с сервером, входом через Steam и админ-панелью
=============================================================

1. ЧТО НУЖНО
   Node.js 18 или новее: https://nodejs.org (кнопка LTS, установить с настройками по умолчанию).
   Больше ничего ставить не нужно: у сервера нет сторонних пакетов.

2. ЗАПУСК НА СВОЁМ КОМПЬЮТЕРЕ
   Распакуйте архив (правой кнопкой → «Извлечь всё») и дважды щёлкните start.bat.
   Сайт сам откроется в браузере по адресу http://localhost:3000.
   Не закрывайте чёрное окно, пока пользуетесь сайтом.
   Файл index.html двойным щелчком открывать не нужно: сайт работает только через сервер.

3. КАК СТАТЬ АДМИНОМ (один раз)
   При первом запуске в чёрном окне сервера появится строка:
       Админ ещё не назначен. ... введи код: XXXXXXXX
   На сайте нажмите «Войти через Steam», войдите своим аккаунтом,
   откройте вкладку «Админ» и введите этот код. С этого момента
   админ-панель и команды работают только для вашего Steam-аккаунта.
   Код знает только тот, у кого открыто окно сервера. После 5 неверных
   попыток код блокируется до перезапуска сервера.

   Другой способ: впишите свой SteamID64 (17 цифр, виден в меню
   аккаунта на сайте) в config.json → "ownerSteamId".

4. АДМИН-КОМАНДЫ (вкладка «Админ» → «Консоль команд»)
   /give <игрок> <сумма>          выдать деньги
   /take <игрок> <сумма>          забрать деньги
   /setbal <игрок> <сумма>        установить баланс
   /giveall <сумма>               деньги всем игрокам
   /giveitem <игрок> <скин> [st]  выдать скин (st — StatTrak)
   /removeitem <игрок> <uid>      забрать предмет
   /clearinv <игрок>              очистить инвентарь
   /givexp <игрок> <опыт>         опыт батл пасса (100 = 1 уровень)
   /premium <игрок> on|off        премиум батл пасса
   /resetbp <игрок>               сбросить батл пасс
   /ban <игрок> [причина]         заблокировать
   /unban <игрок>                 разблокировать
   /kick <игрок>                  выкинуть из аккаунта
   /announce <текст> | off        объявление для всех
   /players [online]              список игроков
   /info <игрок>                  данные игрока
   /stats                         статистика сервера
   /help                          все команды
   Игрок — это имя, часть имени или SteamID64. Имя с пробелами пишите в кавычках.
   Всё это можно делать и кнопками в карточке игрока.

5. ЧТОБЫ ЗАХОДИЛИ ДРУГИЕ ИГРОКИ
   На http://localhost:3000 сайт видите только вы. Для других игроков
   сервер нужно запустить там, где у него будет постоянный адрес:
   VPS (любой хостинг с Node.js) или туннель вроде Cloudflare Tunnel.
   Затем в config.json впишите этот адрес:
       "baseUrl": "https://ваш-адрес.ru"
   Адрес нужен точный: Steam после входа возвращает игрока именно на него.
   Для настоящего сайта используйте https.

6. НАСТРОЙКИ (config.json)
   port           порт сервера (по умолчанию 3000)
   baseUrl        адрес сайта
   ownerSteamId   SteamID64 владельца (можно оставить пустым и ввести код)
   startBalance   баланс новых игроков (по умолчанию 0: деньги даёт только админ)
   steamApiKey    необязательно: ключ Steam Web API для имён и аватаров
                  (https://steamcommunity.com/dev/apikey). Без него имя и аватар
                  берутся из открытого профиля Steam.
   devLogin       оставьте false. Это вход без Steam для проверки на своём компьютере.

7. ДАННЫЕ
   Все аккаунты, балансы и инвентари хранятся в data/db.json.
   Делайте копию этого файла перед обновлениями.
   Чтобы сбросить всё, остановите сервер и удалите data/db.json.

Деньги и предметы на сайте виртуальные. Не принимайте за них реальные
деньги: сайт не рассчитан на настоящие ставки и продажи.
