# CaseLab

Сайт с кейсами CS2: вход через Steam, кейсы, апгрейды, батл пасс, маркет скинов и пополнение баланса.

## Маркет
Вкладка «Маркет»: все скины CS2 из открытой базы ByMykel/CSGO-API (оружие, ножи, перчатки, агенты) во всех износах, StatTrak™ и фазы Doppler.
Сервер сам скачивает базу при запуске и раз в сутки. Если база недоступна, берётся копия `market-catalog.json`.
Цены считаются только на сервере: на 5% ниже Steam (`MARKET_DISCOUNT`). Купленный предмет продаётся обратно ровно за цену покупки.

## Пополнение баланса
* Карты — CloudPayments. Вебхуки в личном кабинете CloudPayments → Сайт → Уведомления:
  * Pay: `https://ВАШ-САЙТ/api/payment/webhook/cloudpayments` (POST, кодировка UTF-8)
  * Check (необязательно): `https://ВАШ-САЙТ/api/payment/webhook/cloudpayments?type=check`
* Криптовалюта — Trybit (бывший CryptoCloud). В проекте → Интеграция и API:
  * URL для уведомлений: `https://ВАШ-САЙТ/api/payment/webhook/trybit`, формат JSON
  * URL успешной оплаты: `https://ВАШ-САЙТ/`

Деньги зачисляются только после проверки подписи вебхука (HMAC-SHA256 у CloudPayments, JWT HS256 у Trybit),
каждый платёж — не больше одного раза. Все ключи — в переменных окружения, пример в `.env.example`.
Файл `.env` никогда не загружайте на GitHub.
